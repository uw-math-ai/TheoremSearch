# Setup & reproducibility

## The reproducibility property

**Design goal:** this repo + the saved **data** is enough to regenerate everything. You could
delete every other working directory (laptop: the old `premise-rl`, `cache/`, the Mathlib and
target-library clones, `/tmp` scratch; klone: the `formalize_rag` work dir and any HF caches we
created) and rebuild all intermediate artifacts from the repo's scripts.

**"The data" to save = the `v2` RDS database** — the team's slogans + embeddings + the ingested
lean-graph metadata (statements, `formal_dependency` edges, `formal_metadata`). It's a managed
cloud DB, so you don't delete it anyway; it is the single ground-truth input. Everything else is
regenerable:

| artifact | regenerated by | source |
|---|---|---|
| embedding index (`cache/formal_emb.f16.npy`, ids) | `build_formal_index.py` | v2 |
| module-held-out split + freq tables | `build_split.py` | v2 |
| trained query head, scaling curve | `train_supervised_full.py` | index |
| formalization eval sets, RAG contexts | `build_formalization_eval.py`, `build_rag_context.py` | v2 + index |
| Qwen3 / Qwen3-Embedding weights | HuggingFace download | public |
| Mathlib / target-library builds | `lake build` after clone | public |
| model generations + typecheck/score | `klone/*.sbatch`, `score_formalization.py` | the above |

The only genuinely external dependencies are **public or shared**: HuggingFace models, a built
Mathlib, a built target library, and (on klone) a vLLM apptainer image. The repo points at
defaults via env vars; substitute your own.

## Local environment
```
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt          # CPU torch is fine: --index-url https://download.pytorch.org/whl/cpu
cp .env.example .env                      # fill in shared RDS credentials (obtain from project owner)
```

## Env vars (see config.py)
| var | meaning | default |
|---|---|---|
| `LPR_ENV_FILE` | path to `.env` | `<repo>/.env` |
| `LPR_CACHE` | artifact dir | `<repo>/cache` |
| `LPR_MATHLIB_DIR` | a project with `import Mathlib` built (for typecheck) | (set me) |
| `LPR_LIB_DIR` | the unfamiliar target library, built (e.g. brownian-motion) | (set me) |

## External builds
- **Mathlib** (for the typecheck harness): clone a project depending on Mathlib at the matching
  toolchain, `lake exe cache get && lake build`, then `export LPR_MATHLIB_DIR=...`.
- **Target library** (unfamiliar-library experiment): clone + `lake build` it; `export LPR_LIB_DIR=...`.
  Then extract its decls with `lake env lean lean/extract_lib_decls.lean` (writes the decl listing).

## GPU steps (klone / L40S)
Generation (`formalize_gen.py`) and embedding (`klone/backtrans_and_embed.py`,
`klone/embed_generic.py`) run inside a vLLM apptainer image with transformers ≥4.57. See
`klone/README.md`. Override `LPR_SIF` (image), `LPR_WORK` (work dir), and `HF_HOME` for model caches.
